# Phishing email analysis web frontend

The Vercel application is [frontend/](frontend/README.md). Its shared API schemas and transport policy are in [contracts/](contracts/README.md).

Set the Vercel **Root Directory to `web/frontend`**, use Next.js with Node 24.x, and include source files outside that directory. See the frontend README for installation, verification and server-only AI configuration.

This publication contains frontend source and contracts. It excludes the Python AI backend, model files, datasets, local secrets, dependencies and build outputs. The existing application at the repository root is preserved.
